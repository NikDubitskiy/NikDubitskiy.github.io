# Research atlas / ND

The visual identity pairs a warm paper background with graphite text and a restrained lime accent. The night palette uses green graphite, pale text and brighter scientific diagram strokes. Golos is self-hosted and supports both languages.

## Composition

- A large two-line name and an integrated portrait establish the homepage hierarchy.
- Numbered sections, thin rules and monospaced metadata reference a research atlas.
- Scientific illustrations keep their explanatory labels and references. No simulated measurements are presented as results.
- Internal pages use the same navigation, type scale, spacing, article lists and form treatments.
- The mobile menu expands in document flow. Navigation remains available without JavaScript.

## Motion and interaction

Finite entrance animations last 0.65–1 seconds. Below-fold sections reveal once, and content is visible without JavaScript. Reduced-motion settings disable entrances and transforms. There is no scroll hijacking, looping animation or custom cursor.

A passive, animation-frame-throttled listener updates reading progress and the active section. Mobile menu supports Escape and returns focus to the trigger. Theme choice persists locally; system preference applies when no choice is stored.

Publication filters, bibliography exports, original-resolution gallery, PDF downloads and mailto drafts retain their existing behavior. Social preview uses the new identity.

## Maintenance

`assets/site.css` provides base content styling; `assets/design.css` defines the atlas identity and responsive overrides. `assets/site.js` progressively enhances interactions. Content and shared navigation are generated by `scripts/content.py` and `scripts/build.py`. Run `python scripts/build.py` after template/content changes and `python scripts/export_cv.py` after print-layout changes.

Checked at 320, 390, 768 and 1440 px, including both themes, keyboard navigation, reduced motion, no-JavaScript navigation, filters, gallery and PDF downloads. All 18 pages retain canonical URLs, language alternates and structured data.
